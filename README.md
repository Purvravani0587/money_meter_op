# Money Meter (money_meter_op)

Money Meter is a Flutter application for tracking recurring incomes, expenses, invoices and basic merchant interactions. This repository contains the mobile client used to register members, authenticate, and view dashboard data.

## Features

- Member registration and authentication
- Dashboard with MTD (month-to-date) stats and projected recurring amounts
- Invoices list with filtered views (All, Paid, Pending)
- Simple masters and profile screens
- Small API testing screen for debugging endpoints

## Project Structure

- `lib/` — Flutter source code
	- `services/` — API and persistence helpers (e.g. `auth_service.dart`)
	- `screens/` — UI screens (login, signup, dashboard, etc.)
- `android/`, `ios/`, `macos/`, `linux/`, `windows/`, `web/` — platform folders generated by Flutter
- `test/` — unit and widget tests

## Prerequisites

- Flutter SDK (>= stable release)
- Android Studio / Xcode for platform builds (optional for web)
- Recommended: an Android/iOS device or emulator

## Local Setup

1. Install dependencies:

```bash
flutter pub get
```

2. Configure the API base URL

- The app uses `lib/services/auth_service.dart` to build API endpoints. By default it points to `https://moneymeter.biz`.
- To change the backend endpoint for local development, edit the `baseUrl` constant in `lib/services/auth_service.dart`.

3. Android-specific notes

- The app requires the `INTERNET` permission. The manifest at `android/app/src/main/AndroidManifest.xml` includes this permission for the main build.
- Cleartext HTTP may be blocked on Android 9+. Prefer using `https://` for API endpoints or configure a network security config when using `http://` during development.

## Run the App

- To run on an Android emulator:

```bash
flutter run -d emulator-5554
```

- To run on iOS simulator (macOS):

```bash
flutter run -d ios
```

## Testing

- Run unit/widget tests:

```bash
flutter test
```

## Troubleshooting

- Socket host lookup / DNS errors (e.g. "SocketFailed host lookup"):
	- Verify your device/emulator has network connectivity.
	- Confirm the domain resolves from your machine: `ping moneymeter.biz` or `dig moneymeter.biz`.
	- Ensure the app is using the correct protocol: prefer `https://` in `baseUrl`.

- App crashes on startup or main screen:
	- Check the debug console for stack traces. Common causes include invalid widget code or missing null checks.
	- Run `flutter analyze` to catch static errors.
